## Breaking changes

| Area | Change | Action |
|---|---|---|
| ESM import assertions | `import assert` syntax removed | Replace with `import ... with` — run codemod |
| `crypto.createCipher` / `createDecipher` | Moved to End-of-Life (removed) | Migrate to `crypto.createCipheriv` / `createDecipheriv` |
| `crypto.Hash` constructor | Runtime deprecated (direct `new Hash()`) | Use `crypto.createHash()` |
| `crypto.Hmac` constructor | Runtime deprecated (direct `new Hmac()`) | Use `crypto.createHmac()` |
| `util.log` and `util.is*` helpers | Runtime deprecated | Replace with native equivalents (see below) |
| `fs.Stats` public constructor | Runtime deprecated | Do not call `new fs.Stats()` directly |
| `stream` default `highWaterMark` | Bumped from 16 KB to 64 KB | Retest streaming behaviour; adjust explicit `highWaterMark` if needed |
| `http` duplicate headers in `writeHead` | Raw header duplicates now preserved after `setHeader` calls | Audit response headers for unintended duplicates |
| `console.assert()` non-string second argument | Treated as a separate argument instead of being coerced to a string | Update assertions that pass non-string messages |
| `--trace-atomics-wait` flag | Runtime deprecated | Remove from scripts and CI configs |
| `--experimental-policy` flag | Deprecated | Migrate to the Permission Model (`--experimental-permission`) |
| `NODE_MODULE_VERSION` bumped to 127 | All native addons must be recompiled | Rebuild or upgrade any native addon dependencies |

## Codemod

### `import assert` → `import ... with`

`import assert { type: 'json' }` was removed. The TC39-standard `with` attribute is now required.

Run the automated codemod:

```bash
npx codemod run @nodejs/import-assertions-to-attributes
```

Grep for remaining occurrences after running:

```bash
grep -rn "assert {" . --include="*.js" --include="*.ts" --include="*.mjs" --include="*.mts"
```

**Before:**
```js
import data from './data.json' assert { type: 'json' };
```

**After:**
```js
import data from './data.json' with { type: 'json' };
```

## Deprecated APIs to migrate

### `crypto.createCipher` / `createDecipher` (removed)

These were removed entirely (end-of-life). They must be replaced before upgrading.

```js
// Before
const cipher = crypto.createCipher('aes192', password);
const decipher = crypto.createDecipher('aes192', password);

// After — use iv-based variants
const key = crypto.scryptSync(password, salt, 24);
const iv = crypto.randomBytes(16);
const cipher = crypto.createCipheriv('aes-192-cbc', key, iv);
const decipher = crypto.createDecipheriv('aes-192-cbc', key, iv);
```

Grep for usages:

```bash
grep -rn "createCipher\b\|createDecipher\b" . --include="*.js" --include="*.ts"
```

### `crypto.Hash` and `crypto.Hmac` direct constructors

```js
// Before (deprecated — throws runtime warning)
const hash = new crypto.Hash('sha256');
const hmac = new crypto.Hmac('sha256', key);

// After
const hash = crypto.createHash('sha256');
const hmac = crypto.createHmac('sha256', key);
```

### `util` deprecated helpers

All `util.is*` type-checking helpers and `util.log` are runtime deprecated. Replace with native equivalents:

| Deprecated | Replacement |
|---|---|
| `util.isArray(v)` | `Array.isArray(v)` |
| `util.isBoolean(v)` | `typeof v === 'boolean'` |
| `util.isBuffer(v)` | `Buffer.isBuffer(v)` |
| `util.isDate(v)` | `v instanceof Date` |
| `util.isError(v)` | `v instanceof Error` |
| `util.isFunction(v)` | `typeof v === 'function'` |
| `util.isNull(v)` | `v === null` |
| `util.isNullOrUndefined(v)` | `v == null` |
| `util.isNumber(v)` | `typeof v === 'number'` |
| `util.isObject(v)` | `v !== null && typeof v === 'object'` |
| `util.isPrimitive(v)` | `typeof v !== 'object' && typeof v !== 'function'` |
| `util.isRegExp(v)` | `v instanceof RegExp` |
| `util.isString(v)` | `typeof v === 'string'` |
| `util.isSymbol(v)` | `typeof v === 'symbol'` |
| `util.isUndefined(v)` | `v === undefined` |
| `util.log(msg)` | `console.log(new Date().toISOString(), msg)` |
| `util._extend(target, src)` | `Object.assign(target, src)` |

Grep for all at once:

```bash
grep -rn "util\.is\|util\.log\|util\._extend" . --include="*.js" --include="*.ts"
```

## Infrastructure and tooling updates

### `.nvmrc` / `.node-version`

```
22
```

### `package.json` engines

```json
"engines": { "node": ">=22.0.0", "npm": ">=10.0.0" }
```

### Dockerfile

```dockerfile
# Before
FROM node:20-bookworm-slim

# After
FROM node:22-bookworm-slim
```

### TypeScript (`tsconfig.json`)

Node.js 22 fully supports ES2023:

```json
{
  "compilerOptions": {
    "target": "ES2023",
    "lib": ["ES2023"]
  }
}
```

### CI/CD (GitHub Actions example)

```yaml
- uses: actions/setup-node@v4
  with:
    node-version: '22'
```

## Notable v22 additions (no action required, but worth adopting)

- `require()` of synchronous ESM graphs — CJS files can now `require()` ESM modules that have no top-level `await`
- Built-in `WebSocket` client enabled by default (global `WebSocket`) — remove `ws` or `isomorphic-ws` polyfills if used only for Node.js compatibility
- `fs.glob` / `fs.globSync` — native glob support, consider replacing `glob` package for simple use cases
- `node --run <script>` — shorthand for `npm run <script>` without spawning npm
- `--watch` mode marked stable
- V8 12.4 with Maglev JIT enabled — up to 20% faster execution on supported architectures
- `node:test` suite improvements: `suite()`, forced exit support, `test:complete` event
