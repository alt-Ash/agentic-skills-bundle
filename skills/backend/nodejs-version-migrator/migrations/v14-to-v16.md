## Contents

- Breaking changes summary

## Breaking changes summary

| Area                             | Change                                                | DEP     |
| -------------------------------- | ----------------------------------------------------- | ------- |
| `module.createRequireFromPath()` | Replaced by `createRequire()`                         | DEP0148 |
| `process.mainModule`             | Replaced by `require.main`                            | DEP0138 |
| `fs.rmdir({ recursive: true })`  | Replaced by `fs.rm({ recursive: true, force: true })` | DEP0147 |
| `os.tmpDir()`                    | Renamed to `os.tmpdir()` (lowercase)                  | DEP0022 |

## Automated codemods

Run these in sequence. Each is idempotent and safe.

### 1. createRequireFromPath → createRequire

```bash
npx codemod run @nodejs/create-require-from-path
```

Before → After:

```js
// Before
import { createRequireFromPath } from 'node:module';
const req = createRequireFromPath('/path/to/module');

// After
import { createRequire } from 'node:module';
const req = createRequire('/path/to/module');
```

### 2. process.mainModule → require.main

```bash
npx codemod run @nodejs/process-main-module
```

Before → After:

```js
// Before
if (process.mainModule === 'mod.js') { ... }

// After
if (require.main === 'mod.js') { ... }
```

### 3. fs.rmdir recursive → fs.rm

```bash
npx codemod run @nodejs/rmdir
```

Before → After:

```js
// Before
fs.rmdir(path, { recursive: true }, callback);
fs.rmdirSync(path, { recursive: true });
fs.promises.rmdir(path, { recursive: true });

// After
fs.rm(path, { recursive: true, force: true }, callback);
fs.rmSync(path, { recursive: true, force: true });
fs.promises.rm(path, { recursive: true, force: true });
```

### 4. os.tmpDir → os.tmpdir

```bash
npx codemod run @nodejs/tmpDir-to-tmpdir
```

Before → After:

```js
// Before
import { tmpDir } from 'node:os';
const foo = tmpDir();

// After
import { tmpdir } from 'node:os';
const foo = tmpdir();
```

## Manual audit (grep patterns)

Before running codemods, verify which patterns exist:

```bash
grep -r "createRequireFromPath" . --include="*.js" --include="*.ts" --include="*.mjs"
grep -r "process\.mainModule" . --include="*.js" --include="*.ts"
grep -r "rmdir.*recursive" . --include="*.js" --include="*.ts"
grep -r "tmpDir()" . --include="*.js" --include="*.ts"
```

## Notable v16 additions (no action required, but useful to adopt)

- `fetch` is not yet available natively in v16 — still requires `node-fetch` or
  similar
- `AbortController` is available globally (no import needed)
- `Array.prototype.at()`, `Object.hasOwn()` are available
- npm 7 ships with v16 (workspaces support)
